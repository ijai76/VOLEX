# VOLEXSTORM 2.0.1

A Horizon shader pack with real shadow maps, water that reflects and refracts the world, leaves and grass in the wind, near-transparent rain, storm fog and a blue night.

The settings screen groups the options into lighting, water, nature, weather, atmosphere and camera.

The manifest structure and the use of the API were learned from Daybreak by hildlabs (MIT) and from the Horizon documentation. The shader code is original.
